# Direction C is a course hybrid with a disagreement map

This narrows the word "uncertainty" in ADR-0001 and supersedes ADR-0009. The blend is unchanged. BasicVSR++ supplies the fidelity frame, using the 4× bicubic checkpoint matched to the benchmark when one exists. The generative frame is official STAR inference, so this direction does not depend on Pyramid Flow or on the course LoRA experiment. Face and text pixels on the bicubic-upscaled frame come from BasicVSR++. Elsewhere the weight is the per-frame-normalized mean absolute RGB difference between the two restorations, with no Gaussian smoothing and no extra global weight. That map is a disagreement map. It is not an uncertainty estimator from EDVR, BasicVSR++, STAR, or UPSR. If STAR does not run, Direction C is a failure case; BasicVSR++ alone is not the hybrid.
