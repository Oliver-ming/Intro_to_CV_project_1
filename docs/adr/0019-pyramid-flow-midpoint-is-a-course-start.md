# Direction A starts at a course midpoint, not official image-to-video

This supersedes ADR-0007. Direction A does not train an upscaler. It is a course SDEdit-style use of Pyramid Flow, not that paper’s super-resolution or image-to-video protocol. Pyramid Flow’s flow runs from noise toward data, and its released image-to-video path keeps a clean first frame and generates the rest. Neither that path nor pure text-to-video enters the metric table. A result counts only when the released code can noise the whole bicubic-upscaled clip and integrate from a start near the middle of the sampler’s own schedule. The table reports the actual start index or noise level and the number of function evaluations. Those values are read off the sampler, not invented. The output is scaled back to the ground-truth resolution. If whole-clip intermediate noising is unsupported, Direction A is a failure case.
